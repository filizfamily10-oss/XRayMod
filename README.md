# XRay Mod 1.8.9

Minecraft 1.8.9 için XRay Mod

## Özellikler
- X tuşu ile XRay'ı aç/kapat
- M tuşu ile Menüyü aç
- 1-6 tuşlarla farklı cevher türlerini seç:
  - 1: Titanium
  - 2: Diamond
  - 3: Gold
  - 4: Iron
  - 5: Emerald
  - 6: Lapis

## Kurulum
1. build.gradle dosyası ile derle: `./gradlew build`
2. JAR dosyasını `.minecraft/mods` klasörüne kopyala
3. Minecraft Launcher'da Forge 1.8.9 seç ve başlat

## Kontroller
- **X**: XRay Aç/Kapat
- **M**: Menü Aç
- **1-6**: Cevher Seç

## Versiyon
- Minecraft: 1.8.9
- Forge: 11.15.1.2318
- Mod Versiyonu: 1.0
